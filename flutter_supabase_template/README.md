# Flutter + Supabase Starter Template

A clean, production-ready Flutter template with Supabase authentication and a beautiful UI foundation.

## 🚀 Features

- **Authentication**
  - Email/OTP passwordless authentication
  - Email/password authentication (optional)
  - OAuth providers ready (Google, Apple, Facebook)
  - Auth state management with auto-refresh routing

- **UI Components**
  - Beautiful Material 3 theme with custom colors
  - Reusable button components (primary, secondary, danger, etc.)
  - Custom dialog component
  - Toast notifications
  - OTP input widget

- **Architecture**
  - Clean service-based architecture
  - go_router for navigation
  - Riverpod ready for state management
  - Organized folder structure

## 🛠 Setup Instructions

### 1. Clone and rename

```bash
# Copy the template
cp -r flutter_supabase_template my_new_app
cd my_new_app

# Rename the project
# Update 'name' in pubspec.yaml
# Update package imports from 'my_app' to your app name
```

### 2. Configure Supabase

1. Create a project at [supabase.com](https://supabase.com)
2. Get your credentials from: Settings > API
3. Update `lib/core/constants/supabase_config.dart`:

```dart
static const String supabaseUrl = 'https://YOUR_PROJECT_ID.supabase.co';
static const String supabaseAnonKey = 'YOUR_ANON_KEY_HERE';
```

### 3. Set up the database

Run this SQL in Supabase SQL Editor:

```sql
-- Create users table
CREATE TABLE public.users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  uid UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL UNIQUE,
  email TEXT NOT NULL,
  display_name TEXT,
  avatar_url TEXT,
  currency_code TEXT DEFAULT 'GBP',
  created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL,
  updated_at TIMESTAMPTZ
);

-- Enable RLS
ALTER TABLE public.users ENABLE ROW LEVEL SECURITY;

-- Users can read their own profile
CREATE POLICY "Users can view own profile" ON public.users
  FOR SELECT USING (auth.uid() = uid);

-- Users can update their own profile
CREATE POLICY "Users can update own profile" ON public.users
  FOR UPDATE USING (auth.uid() = uid);

-- Users can insert their own profile
CREATE POLICY "Users can insert own profile" ON public.users
  FOR INSERT WITH CHECK (auth.uid() = uid);

-- Create trigger to auto-create user profile on signup
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS TRIGGER AS $$
BEGIN
  INSERT INTO public.users (uid, email, display_name)
  VALUES (
    NEW.id,
    NEW.email,
    COALESCE(NEW.raw_user_meta_data->>'display_name', split_part(NEW.email, '@', 1))
  );
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();
```

### 4. Configure deep links (for OAuth)

Update the redirect URL in `lib/services/auth_service.dart`:

```dart
static const String _redirectUrl = 'com.yourcompany.yourapp://login-callback';
```

Add to `android/app/src/main/AndroidManifest.xml`:

```xml
<intent-filter>
  <action android:name="android.intent.action.VIEW" />
  <category android:name="android.intent.category.DEFAULT" />
  <category android:name="android.intent.category.BROWSABLE" />
  <data android:scheme="com.yourcompany.yourapp" android:host="login-callback" />
</intent-filter>
```

Add to `ios/Runner/Info.plist`:

```xml
<key>CFBundleURLTypes</key>
<array>
  <dict>
    <key>CFBundleURLSchemes</key>
    <array>
      <string>com.yourcompany.yourapp</string>
    </array>
  </dict>
</array>
```

### 5. Install dependencies

```bash
flutter pub get
```

### 6. Run the app

```bash
flutter run
```

## 🎨 Customization

### Colors

Edit `lib/core/theme/app_colors.dart`:

```dart
static const Color primary = Color(0xFF009688);  // Your brand color
static const Color accent = Color(0xFFec332f);   // Secondary color
```

### Fonts

Edit `lib/core/theme/app_typography.dart` to change fonts. Default uses:
- **Lato** for headlines
- **Source Sans 3** for body text

### App Name

Update in `lib/core/constants/app_constants.dart`:

```dart
static const String appName = 'My App';
static const String appTagline = 'Your tagline here';
```

## 📱 Adding New Features

### Add a new screen

1. Create screen in `lib/features/your_feature/screens/`
2. Add route in `lib/routing/app_router.dart`
3. Create service in `lib/services/` if needed
4. Create model in `lib/models/` if needed

### Add a new model

```dart
// lib/models/post.dart
class Post {
  final int id;
  final String title;
  final String content;
  final DateTime createdAt;

  Post({...});

  factory Post.fromJson(Map<String, dynamic> json) => Post(...);
  Map<String, dynamic> toJson() => {...};
}
```

### Add a new service

```dart
// lib/services/post_service.dart
class PostService {
  final _client = SupabaseService.client;

  Future<List<Post>> getPosts() async {
    final response = await _client.from('posts').select();
    return response.map((json) => Post.fromJson(json)).toList();
  }
}
```
